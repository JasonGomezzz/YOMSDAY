# YOMSDAY

Invitación cinematográfica para el cumpleaños de Yonsito, programado para el 26 de septiembre de 2026 a las 10:00 p. m. (hora de Lima).

## Desarrollo

```bash
npm install
npm run dev
```

La aplicación queda disponible en [http://localhost:3000](http://localhost:3000).

## Verificación

```bash
npm run lint
npm test
npm run build
```

## Configuración del evento

Los datos de fecha, ubicación y confirmación se mantienen centralizados en `src/config/event.ts`.

## Despliegue

El proyecto está preparado para conectarse directamente con Vercel mediante la rama `main`. No requiere variables de entorno ni servicios externos.
